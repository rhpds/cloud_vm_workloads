= rhel-fsc-ee

Lightweight execution environment for the RHEL Field Sourced Content runner.
Built from `ubi9/python-314` with only what FSC playbooks need.
All collections install from Galaxy — no Automation Hub tokens required.

== Build

From the `cloud_vm_workloads` repo root:

----
podman build --platform linux/amd64 \
  -t quay.io/rhpds/rhel-fsc-ee:latest \
  tools/execution_environments/rhel-fsc-ee
----

== Push

----
podman push quay.io/rhpds/rhel-fsc-ee:latest
----

== What's included

* `ansible-core`, `ansible-runner`, `paramiko` (SSH)
* AWS CLI + `boto3`
* Collections: `ansible.posix`, `community.general`, `community.crypto`, `containers.podman`, `fedora.linux_system_roles`, `amazon.aws`

Authors install additional collections at runtime via `requirements.yml` in their git repo.
