= rhel-fsc-ee

Wrapper around `quay.io/agnosticd/ee-multicloud` for the RHEL Field Asset runner.

Same packages and collections. Different launch: ansible-builder uid/homedir papering, then `exec` of the command. No `install_dynamic_dependencies.yml`, no AAP/navigator argument rewriting.

== Build

----
podman build \
  -t quay.io/rhpds/rhel-fsc-ee:latest \
  tools/execution_environments/rhel-fsc-ee
----

Bump `BASE_IMAGE` in the Containerfile when you want a newer ee-multicloud.

== Push

----
podman push quay.io/rhpds/rhel-fsc-ee:latest
----

The runner default is `quay.io/rhpds/rhel-fsc-ee:latest`.
